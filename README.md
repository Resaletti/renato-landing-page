# 🚀 Renato Saletti Santos | Professional Landing Page

A modern and responsive personal landing page designed to introduce my professional profile through a clean, elegant, and user-focused experience.

This project serves as a digital business card, allowing recruiters, hiring managers, and professional contacts to quickly access my résumé, portfolio, and career journey by simply scanning a QR Code.

## 🎯 Purpose

The goal of this project is to create a memorable first impression while showcasing both my technical abilities and my professional background.

Visitors can:

* 📄 Download my résumé
* 👨‍💻 Explore my development portfolio
* 📈 Learn about my professional journey
* 🔗 Connect with me through LinkedIn and GitHub

---

## ✨ Features

* Modern and minimalist interface
* Mobile-first responsive design
* Smooth animations with Framer Motion
* Glassmorphism visual effects
* Premium UI inspired by Apple, Vercel, and Stripe
* Fast loading and optimized performance
* QR Code friendly experience

---

## 🛠️ Built With

* HTML5
* CSS3
* Google Fonts (Inter)
* Responsive Design
* Modern CSS (Flexbox, Gradients, Glassmorphism)
